ONIDIA: OmNIpresent DIgital Amigo

Onidia is a lightweight desktop companion written in pure Go using direct X11 bindings, rendering a chibi anime character that roams your screen with near-zero CPU usage and a minimal memory footprint. Beyond simple idling and physics-driven interactions like throwing or parachuting, she features dynamic facial expressions, animated activities, and interactive speech bubbles powered by a local named pipe.

› Core Capabilities: Supports 32-bit ARGB per-pixel transparency, sixteen expressive moods, interactive mouse controls (drag, fling, hop), customizable event overlays (such as confetti or Matrix rain), and actionable routines like skipping rope or playing guitar.
› Technical Footprint: Built with zero external C dependencies (cgo) or heavy GUI toolkits, requiring only Go 1.21+, an X11/XWayland display, and a compositing window manager.

KAMA: Knowledge Augmented Mining Agent

Retrieval-Augmented Generation shouldn't require glueing together twelve messy libraries. KAMA is a turnkey, plug-and-play RAG-as-a-service engine. Drop in messy PDFs, Notion dumps, Git repos, or technical docs—it handles chunking, hybrid dense/sparse vector indexing, and spits out grounded answers with exact source page citations instead of making stuff up.

› Hybrid Search: Combines dense semantic embeddings with sparse BM25 keyword matching and cross-encoder reranking.
› Strict Grounding: Rejects prompts where documents don't have evidence, achieving a verified 99.4% citation accuracy.
